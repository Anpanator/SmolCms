== Project constants

`constants.php` defines `ROOT_DIR` and `PHP_TEMP_DIR` (PHP's current system
temporary directory). `config.php` groups the filesystem allowlists and the
migration, image-storage, processing-lock, and application-log path settings.
Use it as the source for these configured paths rather than copying path
literals into deployment notes or code.

Change these settings when moving application data, narrowing filesystem
access, relocating PHP's upload temporary directory, or choosing a different
log location. Keep the directories, allowlists, and PHP-FPM/CLI permissions in
sync; see <<_installation_and_setup>> and
<<_directory_access_restrictions>>.

`AccessLevel` is the int-backed role type used for authorization and persisted
with user records; its cases are deliberately not enumerated here.
