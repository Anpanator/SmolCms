== Application flow

. `src/app.php` loads `constants.php`, `config.php`, and Composer's autoloader,
  then builds the service graph and resolves `ApplicationCore`.
. `ApplicationCore::init()` restricts PHP file access, registers the database-backed session handler, and resumes a valid session.
. CLI invocations run the selected command. HTTP requests are built from the
  request environment and matched to a route by both path and HTTP method.
. Before a handler runs, the pre-controller chain checks request origin,
  authorization, request mapping, and validation. The handler then produces a
  response.
. An unmatched route returns `404`; a `BadRequestException` maps to `400`, and
  other handler errors or invalid handler results map to `500`.

Image variants are generated asynchronously by `--process-images`; the Docker
container runs this command in a background worker. See <<_image_uploads>> for
the upload lifecycle and <<_error_handling_and_responses>> for response
behavior.
