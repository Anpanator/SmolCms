== Testing

Install dependencies and run the PHP and frontend suites:

[source,shell]
----
composer install
vendor/bin/phpunit
----

The dependency-free frontend suite has a matching `*.test.js` module for each
frontend JavaScript module, including `main.js`. PHPUnit runs it in headless
Chromium through `tests/frontend/runner.html`; Chromium is required and can be
selected with `CHROMIUM_BINARY`. No alternate browser or skipped-test path is
used.

`SimpleTestCase` initializes properties marked with `#[Mock(...)]` and
`#[Stub(...)]`; overridden `setUp()` methods must call `parent::setUp()`.
`FunctionalTestCase` uses an in-memory SQLite database and
`simulateRequest()` for HTTP-level tests. Its `loginUser()` helper creates a
user at the default `NOVICE` access level; use the role-specific helper when a
test needs a higher gate. Database rows persist across methods in a functional
test class, while sessions are cleared between tests.

PHPUnit's `executionOrder` is `defects`; dependency resolution is configured
separately. The suite treats warnings, notices, output, risky tests, and other
PHPUnit issues as failures.
