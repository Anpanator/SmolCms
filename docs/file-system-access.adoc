== File system access

`FileSystemAccessService` adds an application-level allowlist on top of PHP's
`open_basedir`. It canonicalizes configured roots and existing paths before
checking that operations stay inside an allowed root; this catches ordinary
path traversal and symlink escapes, but does not replace OS permissions or
protect against filesystem races.

Every configured root must exist when the service is constructed. For example,
thumbnail writes under `public/img/thumb` are allowed because they remain
inside the configured `public/img` root. Add or move a storage root only after
it exists and is also covered by PHP's directory restriction. See
<<_directory_access_restrictions>> for that separate boundary.
