[#_cli_commands]
== CLI Commands

Commands run through `php src/app.php`. Non-flag values following a command are
passed as its arguments. Run `php src/app.php` without a command to print the
full `Available commands:` list. `--reset` modifies `--init-db`, while
`--noconfirm` suppresses confirmation prompts; modifiers do not run commands
by themselves.

|===
| Command | Description

| `--generate-migration "<description>"`
| Creates an empty, timestamped SQL migration file in `private/sql`; edit it
before applying migrations.

| `--migrations`
| Applies pending, non-empty `.sql` migrations in filename order and records
successfully executed filenames in the `migration` table. A confirmation
prompt can be skipped with `--noconfirm`.

| `--init-db`
| Initializes an empty database and leaves an existing one unchanged. Add
`--reset` to drop and recreate its tables; this destructive operation prompts
unless `--noconfirm` is supplied.

|===

For example, create and apply a migration:

[source,shell]
----
php src/app.php --generate-migration "add image metadata"
# Edit the generated SQL file.
php src/app.php --migrations --noconfirm
----

In CLI mode, the application exits successfully after the command handler
returns normally, including when it prints the command list. An executor
exception escapes before that successful exit.
