== Development rules

* Require PHP 8.5 or newer; every PHP file uses `declare(strict_types=1);`.
* Do not use `@` to suppress warnings or notices anywhere in the project, or
  rely on deprecated functionality.
* Keep the test suite free of failures, warnings, notices, risky tests, and
  skips.
* Frontend code is plain JavaScript and CSS under `public/`; there is no
  framework, Node.js dependency, or build step.
* No build, lint, typecheck, or code-generation task is configured;
  `phpunit.xml` defines the verification suite.
