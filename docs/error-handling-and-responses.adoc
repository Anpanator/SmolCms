== Error handling and responses

An unmatched route returns `404`. `BadRequestException` becomes `400`; other
exceptions from the pre-controller chain or controller become `500`. These
framework error responses normally have empty bodies, but PHP's
`display_errors` setting can cause an exception stack trace to be included.

Exceptions are logged: bad requests at informational level and other failures
as errors. Validation details are retained in the log, not returned as an API
message. The SPA uses status codes for user-facing errors.

`JsonResponse` JSON-encodes response data and sets the JSON content type. A
`null` payload leaves the body empty (for example, `204 No Content`); protected
image-file responses use ordinary `Response` headers for internal Nginx
delivery instead.
