[#_validation]
== Validation

Validation attributes describe constraints on request-object properties.
`Validator` evaluates property rules and can recursively validate nested
objects with `ValidateObject`; multiple different rules may be applied to one
property. Null is allowed unless a rule such as `ValidateNotNull` rejects it.

[source,php]
----
readonly class UserSettingsUpdateRequest extends ValidatedRequest
{
    public function __construct(
        Request $rawRequest,
        #[ValidateNotNull]
        #[ValidateStringSize(minLength: 1, maxLength: 69)]
        public ?string $displayName,
    ) {
        parent::__construct($rawRequest);
    }
}
----

The backend validates mapped `ValidatedRequest` objects. The browser mirrors
field rules in `public/js/validation.js` for faster feedback; it measures
Unicode code points and keeps email checks aligned, but server validation is
authoritative. Custom property rules implement `PropertyValidationAttribute`.
